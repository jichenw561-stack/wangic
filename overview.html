三个飞轮
平台的生命力来源
⟳
生产 — 使用 — 进化
公司萃取各条线经验 → 快速推出基础 Skill → 用户使用中交互反馈 → 形成个性化 Skill → 平台闭环学习优化
◉
信息 — 洞察 — 推送
后台 Skill 持续扒取海外研报/闭门会议/热点新闻 → 与公司深度内容结合 → 主动推送给研究员/领导，提示新 idea
⬡
工具 — 共创 — 生态
业务使用 Skill → 倒逼开发团队封装更多 Tool → Tool 越丰富 Skill 越强大 → 吸引更多业务场景接入
使用端形态：桌面客户端
类 Claude 体验，投研版 IDE
🖥️
使用端采用桌面客户端而非纯 Web 页面——研究员有大量本地文件（研报、笔记、数据文件）， 客户端可直接读取本地工作区作为知识库，无需逐一上传。纯 Web 页面无法获取用户本地目录。
📂
本地工作区访问
研究员指定本地文件夹作为工作区，平台可直接读取其中的研报、笔记、数据文件，无需上传。
🔍
个人知识库 RAG
对工作区内文件进行向量化索引，支持 RAG 检索。提问时自动关联本地知识，回答更精准。
🔒
安全与权限管控
本地未上传的 Skill 不开放 Tool 调用权限；官方精品 Skill 加密保护；数据流控与权限管理到位。
