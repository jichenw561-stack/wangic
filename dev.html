# 宏观数据周报 ## 描述 每周自动生成宏观经济数据周报，涵盖 GDP、CPI、PMI 等核心指标的 最新数据及趋势分析。 ## 触发方式 - 自然语言："帮我看看最近的宏观数据"、"生成宏观周报" - 定时触发：每周一 08:00 ## 工具调用 - @宏观数据取数 → 获取最新 GDP/CPI/PMI 等指标 - @环同比计算 → 计算同比环比变化 - @图表生成 → 生成趋势图表 ## 输出格式 1. 核心指标速览：表格形式，含最新值、环比、同比 2. 趋势分析：每个指标 2-3 句点评 3. 关注要点：本周需重点关注的宏观事件 4. 风险提示：潜在风险因素 ## 参考模板 按华泰研究所标准格式输出
调用工具： 宏观数据取数 环同比计算 图表生成 发布范围：团队内

""" BD潜力评估模型 - MCP Tool封装 华泰证券算法团队 """ from mcp_server import MCPTool, Field class BDPotentialTool(MCPTool): """评估创新药BD（Business Development）潜力""" name = "bd_potential_assessment" description = "输入目标公司和管线信息，返回BD潜力评分及分析" # 入参定义 company: str = Field(description="目标公司名称") pipeline_stage: str = Field( description="管线阶段", enum=["临床前", "I期", "II期", "III期", "已上市"] ) indication: str = Field(description="适应症领域") async def execute(self, **params): # 1. 获取公司基本面数据 fundamentals = await self.call_tool( "stock_fundamentals", company=params["company"] ) # 2. 管线价值评估 pipeline_value = self._evaluate_pipeline( stage=params["pipeline_stage"], indication=params["indication"] ) # 3. 综合评分 score = self._calculate_score(fundamentals, pipeline_value) return {"score": score, "rating": self._get_rating(score)}
